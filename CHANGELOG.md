## [1.0.0] - 2026-09-08

### Added

- Initial release of Gitfella
- GitHub username based login, no authentication required
- Profile, Fans, Not Following Back, and Fellas views
- Raw data export with JSON preview and copy to clipboard
- Light, dark, and system theme support
- Rate limit aware syncing with GitHub's public API
