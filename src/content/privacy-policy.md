# Privacy Policy

_Last updated: September 04, 2026_

Gitfella is a tool for exploring your GitHub followers and following data. This page explains what information the app accesses and how it's handled.

## What We Access

Gitfella only accesses publicly available GitHub data, including your profile information, followers list, and following list, using GitHub's public REST API. We do not request or use GitHub OAuth, access tokens, or any private account data.

## What We Store

Your GitHub username is stored locally in your browser's local storage, so you don't need to re-enter it on future visits. Fetched profile, followers, and following data is temporarily cached in your browser's memory during your session to avoid unnecessary requests to GitHub's API.

Gitfella does not have a backend server or database. No data you provide or that is fetched on your behalf is transmitted to or stored on any server we control.

## Third-Party Data

All data displayed in Gitfella comes directly from GitHub's public API. GitHub's own [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement) governs how GitHub itself handles that data.

## Analytics

Gitfella uses [Vercel Analytics](https://vercel.com/analytics) to understand basic usage patterns, such as page views. Vercel Analytics is privacy-focused and does not use cookies or collect personally identifiable information. For more details, see [Vercel's Privacy Policy](https://vercel.com/legal/privacy-policy).

Gitfella does not use any other analytics, tracking, or advertising services.

## Changes to This Policy

This policy may be updated from time to time. Continued use of Gitfella after changes are posted constitutes acceptance of the updated policy.
